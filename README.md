## Highlights & Features

- **Multi-Page Case Study System**: Dynamic case study routing (`project.html`) for 8 full-scale engineering projects with architecture pipelines, executive overviews, and challenges.
- **Flagship SaaS Showcase**: Features **ClinicFlo AI** (Healthcare Management SaaS Platform) and **Smart Energy Consumption Analyzer** (DevOps & Telemetry pipeline).
- **Interactive 3D Ambient Engine**: Real-time canvas particle network reacting to cursor coordinates and scroll momentum.
- **3D Isometric Architectural Backgrounds**: Custom-rendered volumetric 3D assets in deep forest, olive, and gold.
- **3D Card Perspective Tilt**: Subtle hover parallax micro-interactions across projects and domains.
- **Performance First**: Zero bloated frameworks — pure, optimized Vanilla HTML5, CSS3, and JavaScript.
- **Olive Garden Design System**: Custom curated palette (`#606C38` Olive, `#283618` Deep Forest, `#FEFAE0` Warm Cream, `#DDA15E` Gold).
- **Fully Responsive & Accessible**: Supports desktop, tablet, and mobile with keyboard navigation and reduced-motion preferences.

## Local Development

To run locally:

```bash
# Clone the repository
git clone https://github.com/Usman22Siddiqui/portfolio-v2.git

# Navigate to project folder
cd portfolio-v2

# Start a local static server
npx -y serve . -l 3000
```

Open `http://localhost:3000` in your browser.

---

## Deployment (Vercel)

This repository is pre-configured for instant zero-configuration deployment on **[Vercel](https://vercel.com/)**:

1. Import this repository in your Vercel dashboard.
2. Leave build settings as default (Static HTML).
3. Click **Deploy**.
